# #11 Rule-based rubric

- Set out to: score answers for format, stopping, repetition, domain terms and invented numbers, as one module shared by DPO pair building (#2) and the eval harness (#3).
- Decision: five rules; finance rows are classed by the prompt, and figures match as value sets (`5%` equals 0.05) (`docs/decisions.md`, "Class finance rows by the prompt...").
- Found: on the 2,200 references, 2,170 pass (98.6%) and 283 rows (12.9%) are finance (`outputs/rubric_references/v1/summary.json`, commit 723c41a, clean).
- Per rule: `domain_terms` 96.8%, `repetition` 99.1%, `format` 99.95% (same file).
- Limit: with the reference removed as a number source, 105 of 283 finance references (37.1%) fail `ungrounded_numbers` (same file). It checks grounding, not truth.
- A scratch run before de-duplication gave 23.4% finance rows (`docs/decisions.md`); see #15.
